# BIOBUZZ Driver Practice

A 2:00 TELEOP period of FTC 2026–27 BIOBUZZ on the team's physics simulator (Unity, WebGL), for driver practice in the
browser with a gamepad (Logitech F310 / Xbox / PlayStation) or the keyboard.

Play: https://not-gud-enof.github.io/biobuzz-practice/

This repository only hosts the built website. It is generated from the simulator project with
`FieldSceneBuilder.BuildWebPractice` and `tools/web_practice/package.py`.
